# 📚 LearnAtHome

## Application Introduction

LearnAtHome is a modern home tuition management application designed to connect students, parents, tutors, and administrators on a single platform. The application provides a simple, responsive, and user-friendly interface for managing users and educational activities efficiently.

The platform supports **four user roles**:

- 👨‍💼 **Admin** – Manages the entire application.
- 👨‍🏫 **Tutor** – Provides tuition services and manages students.
- 🎓 **Student** – Accesses learning resources and tuition details.
- 👨‍👩‍👧 **Parent** – Monitors their child's learning and tuition activities.

---

## 🛠️ Admin Dashboard Features

The Admin Dashboard allows administrators to manage the application efficiently.

### Current Features

- Dashboard overview
- User management
- Search users
- Filter users
- Block users
- Delete users
- Responsive sidebar
- Light/Dark mode support

> More dashboard modules and features will be added in future updates.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/LearnAtHome.git
```

### 2. Go to the Project Folder

```bash
cd LearnAtHome
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```
